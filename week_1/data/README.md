# Data sources

Public data: UCI Machine Learning Repository — Online Retail (https://archive.ics.uci.edu/dataset/352/online+retail). Download `Online Retail.xlsx` from the source and place it in this folder. The dataset is not included in this repository. Review the dataset license/usage terms before redistributing it.

The Python example can run without this file using synthetic daily sales observations. These synthetic values are for code illustration only and must not be presented as real business results.
